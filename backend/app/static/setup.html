Aruvi Setup Helper

Generate your Telegram session string. Pick whichever path you prefer.

Option A — Run on your server recommended · battle-tested

SSH into the machine hosting Aruvi and run:

cd /home/container/grabber-deploy/backend && npx -y telegram-session-generator
  1. Paste your api_id and api_hash when prompted (from my.telegram.org).
  2. Enter your phone number → Telegram sends you a login code.
  3. Enter the code (+ 2FA password if enabled).
  4. Copy the printed session string into your .env, then restart the backend.

Your API credentials for reference: 35927937 / c77b…d24 (already in this server's .env).

Option B — In your browser zero install

An open-source (MIT) client-side tool that runs MTProto entirely in your browser and can export Pyrogram-format strings directly.

https://aaruvi.space/telegram-tools/

Choose Generator → User, enter the same api_id/api_hash + phone, then export as Pyrogram.
